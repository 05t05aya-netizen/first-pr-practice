# first-pr-practice

A tiny sample project with a couple of usefull helper functions.

## Functions

- `add(a, b)` - adds two numbers
- `greet(name)` - returns a greeting string

## 学習ノート

- [株式投資の基礎知識ノート](docs/stock-basics.md) — 口座開設から財務諸表の読み方、
  リスク管理、行動バイアスまでをまとめた学習用ドキュメント
- [`stock_tools.py`](stock_tools.py) — ノート内の計算式（ポジションサイジング、複利、
  PER/PBR、配当利回りなど）を関数にしたもの
