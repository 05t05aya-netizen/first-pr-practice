## 1. 投資を始める前の土台

株の知識よりも先に固めるべき順序があります。ここを飛ばすと、相場が悪化したときに
「本来売らなくていい局面で売らざるを得ない」状態になります。

| 優先順位 | やること | 目安 |
| --- | --- | --- |
| 1 | 高金利の借金を返す | カードローン・リボ（年15%前後）は、どんな投資リターンより確実に高コスト |
| 2 | 生活防衛資金を現金で確保 | 会社員なら生活費6ヶ月分、自営業なら12ヶ月分 |
| 3 | 5年以内に使う予定のお金を分離 | 教育費・住宅頭金などは株式に入れない |
| 4 | 余剰資金で投資を開始 | 「最悪ゼロでも生活が壊れない」金額 |

### リスク許容度を決める

投資額を決める前に、自分の「耐えられる下落幅」を数字で決めます。

- **時間軸**: 投資期間が長いほど株式比率を高くできる（回復を待てるため）
- **心理耐性**: 資産が -30% になったとき、追加投資できるか／狼狽売りするか
- **収入の安定性**: 給与が景気に連動する職種（不動産・金融・広告）は、株式比率を下げる方が整合的

> 目安のストレステスト: 全世界株式は過去に **-50%超** の下落を複数回経験しています。
> 「投資額 × 50% の含み損」を金額で書き出して、耐えられる額に投資額を調整してください。

## 2. 株式のしくみ

### 株式とは

株式は**企業の所有権の一部**です。1株持つことは、その会社の利益・純資産に対する
持分を持つことを意味します。株主の権利は主に3つ。

- **利益配分請求権**: 配当を受け取る
- **議決権**: 株主総会で経営に投票する
- **残余財産分配請求権**: 解散時に債権者の後で残余を受け取る（=最劣後）

### 株価は何で決まるか

短期と長期で決定要因が違う、というのが最重要ポイントです。

- **長期（数年）**: 企業が生み出す将来キャッシュフローの現在価値。つまり **業績**。
- **短期（数日〜数ヶ月）**: 需給と期待の変化。「良い決算でも下がる」のは、
  すでに株価がそれ以上の期待を織り込んでいたため（**織り込み済み**）。

株価 ≒ **EPS（1株利益） × PER（期待の倍率）** と分解して考えると、
「業績が伸びたのに株価が下がった＝PERが縮んだ」といった動きを説明できます。

### 株価を動かすマクロ要因

| 要因 | 株式への一般的な影響 | 理由 |
| --- | --- | --- |
| 金利上昇 | マイナス（特にグロース株） | 割引率が上がり、将来利益の現在価値が減る |
| 景気拡大 | プラス | 企業利益の増加 |
| 円安 | 輸出企業にプラス／輸入・内需にマイナス | 円換算の売上・仕入コストが変動 |
| インフレ | 中立〜まちまち | 価格転嫁できる企業は耐性あり |

## 3. 取引の実務

### 注文の種類

| 注文 | 内容 | 使いどころ | 注意点 |
| --- | --- | --- | --- |
| 成行（なりゆき） | 値段を指定せず、今の相場で約定 | 確実に売買したいとき | 流動性が低い銘柄では想定外の価格で約定する |
| 指値（さしね） | 価格を指定 | 価格をコントロールしたいとき | 約定しないことがある |
| 逆指値 | 「◯円以下になったら売り」 | 損切りの自動化 | ギャップダウン時は指定値より下で約定 |

### 覚えておく実務知識

- **単元株**: 日本株は原則 100株単位。株価3,000円なら最低30万円。
  資金が小さいうちは**単元未満株（ミニ株）** サービスで1株から買えます。
- **約定（やくじょう）と受渡**: 日本株は約定日から起算して2営業日後（T+2）に決済。
- **ザラ場と板**: 取引時間中の値動きがザラ場。板（気配値）は売り買いの注文の並び。
  板が薄い（注文が少ない）銘柄は、自分の注文で価格が動くので初心者は避けるのが無難。
- **流動性**: 1日の売買代金が小さい銘柄は「買えるが売れない」リスクがある。
  目安として売買代金が数億円未満の銘柄は、最初のうちは対象外にしておくと安全。
- **手数料**: 主要ネット証券は日本株の売買手数料が無料化されています。
  一方、米国株は為替スプレッド（1ドルあたり25銭など）が実質コストになります。

## 4. 税金と制度（NISA・特定口座）

### 課税の基本

上場株式の譲渡益・配当には **20.315%**（所得税15% + 復興特別所得税0.315% + 住民税5%）が課税されます。

### 口座の種類

| 口座 | 確定申告 | 特徴 |
| --- | --- | --- |
| 特定口座（源泉徴収あり） | 原則不要 | 証券会社が損益計算と納税を代行。最初はこれでよい |
| 特定口座（源泉徴収なし） | 必要 | 年間取引報告書は作ってくれる |
| 一般口座 | 必要 | 自分で損益計算。基本的に選ぶ理由はない |
| NISA口座 | 不要 | 非課税。ただし損益通算・繰越控除ができない |

### NISA（2024年〜の新制度）

- **つみたて投資枠**: 年120万円。長期・積立・分散に適した投資信託が対象。
- **成長投資枠**: 年240万円。個別株・ETF・投資信託など。
- **合計**: 年360万円、生涯投資枠 1,800万円（うち成長投資枠は1,200万円まで）。
- 売却すると翌年に**簿価ベースで枠が復活**する（回転売買前提の制度ではない点に注意）。

### 損益通算と繰越控除（課税口座のみ）

- 同一年の利益と損失は相殺できる（**損益通算**）。
- 相殺しきれない損失は確定申告で**3年間繰り越せる**（繰越控除）。
- **NISA口座の損失は通算も繰越もできない**。これはNISAの数少ないデメリット。

### 米国株の配当

米国で10%源泉徴収された後、日本で20.315%が課税されます（二重課税）。
確定申告で**外国税額控除**を使うと一部が取り戻せます。
なお **NISA口座では米国側の10%は取り戻せません**（外国税額控除が使えないため）。

## 5. 財務諸表の読み方

個別株を買うなら、最低限この3つは見ます。決算短信・有価証券報告書に載っています。

### 損益計算書（P/L）— 1年でいくら儲けたか

```
売上高
 − 売上原価        → 売上総利益（粗利）……商品そのものの competitiveness
 − 販管費          → 営業利益      ……本業の儲け。最重要
 ± 営業外損益      → 経常利益      ……財務活動込み
 ± 特別損益 − 税金 → 当期純利益    ……最終利益。一過性の損益が混ざる
```

見るポイント:
- **売上高と営業利益が両方伸びているか**（売上だけ伸びて利益が伸びないのは値引き競争のサイン）
- **営業利益率**の推移（同業他社比較で価格決定力がわかる）

### 貸借対照表（B/S）— 今どんな財産と借金があるか

```
資産 = 負債 + 純資産
```

- **自己資本比率** = 純資産 ÷ 総資産。40%以上あれば財務は概ね健全（業種により差あり）。
- **有利子負債**が営業キャッシュフローの何年分か（10年分以上は要注意）。

### キャッシュフロー計算書（C/F）— 実際の現金の動き

| 区分 | 健全な状態 | 危険なサイン |
| --- | --- | --- |
| 営業CF | プラス（利益と近い水準） | 利益は黒字なのに営業CFがマイナス＝**黒字倒産の予兆**、売掛金・在庫の急増 |
| 投資CF | マイナス（成長投資している） | ずっとゼロ＝先細り |
| 財務CF | 成長期はプラス、成熟期はマイナス（配当・自社株買い） | 営業CFマイナスを借入で埋めている |

> **利益は意見、キャッシュは事実**。会計上の利益は見積りで動きますが、現金残高は動きません。
> 迷ったら営業CFを見てください。

## 6. 投資指標とバリュエーション

### 主要指標

| 指標 | 計算式 | 意味 | 注意点 |
| --- | --- | --- | --- |
| EPS | 純利益 ÷ 発行済株式数 | 1株あたり利益 | 自社株買いで機械的に増える |
| PER | 株価 ÷ EPS | 利益の何年分の値段か | 業種で水準が全く違う。赤字だと計算不能 |
| BPS | 純資産 ÷ 発行済株式数 | 1株あたり純資産 | |
| PBR | 株価 ÷ BPS | 純資産の何倍か | 資産の質（不良在庫・のれん）を見ないと無意味 |
| ROE | 純利益 ÷ 自己資本 | 株主資本の運用効率 | 借金を増やしても上がる（後述） |
| ROIC | 税引後営業利益 ÷ 投下資本 | 事業そのものの効率 | ROEより実力を反映しやすい |
| 配当利回り | 年間配当 ÷ 株価 | 配当の利回り | **高利回りは株価下落の結果**であることが多い |
| 配当性向 | 配当 ÷ 純利益 | 利益の何%を配当に回すか | 100%超は持続不能 |

### 指標の落とし穴

- **低PER = 割安ではない**。市場が将来の減益を織り込んでいる場合、PERは低いまま下がり続けます
  （**バリュートラップ**）。「なぜ安いのか」の説明ができないなら買わない。
- **ROEはデュポン分解で見る**:
  `ROE = 売上高純利益率 × 総資産回転率 × 財務レバレッジ`
  借金（レバレッジ）を増やすだけでROEは上がるので、高ROEが**収益性由来か借金由来か**を分解して確認します。
- **同業種・同社の過去レンジと比較する**。「PER 15倍は割安」といった絶対水準の議論は無意味です。

### バリュエーションの本質

理論的には、株式の価値は**将来のフリーキャッシュフローを割引率で現在価値に割り引いた合計**です（DCF）。
個人が精密なDCFを組む必要はありませんが、この考え方から次が導けます。

- 金利（割引率）が上がると、利益が遠い将来にある成長株ほど価値が下がる
- 「成長率」と「その成長が続く期間」の見込みが、バリュエーションのほぼ全て
- **株価 = 業績 × 期待**。期待は測れないので、**期待が高すぎる銘柄を避ける**方が現実的

## 7. テクニカル分析の位置づけ

チャート分析は「将来を当てる道具」ではなく、**需給と参加者心理の記録**として使うのが妥当です。

### 最低限知っておくもの

- **移動平均線（MA）**: 一定期間の終値の平均。25日・75日・200日が代表的。
  価格がMAより上か下かで、大まかなトレンドの向きを把握する。
- **出来高**: 価格変動の「重み」。出来高を伴わない上昇は続きにくい。
- **サポート／レジスタンス**: 過去に何度も反発した価格帯。多くの参加者が意識するため機能しやすい。
- **トレンドフォロー vs 逆張り**: どちらを採るかを**先に決める**。混ぜると、上昇では利確が早く、
  下落では「逆張り」と称してナンピンする最悪の組み合わせになります。

### 限界を理解する

- 同じチャートを見ても解釈は人によって割れる（後付け説明になりやすい）
- インジケーターを増やしても精度は上がらない（相関の高い指標を重ねているだけ）
- **短期売買はゼロサムに近い**。手数料とスプレッド、税金の分だけマイナスサム。
  プロと同じ土俵で戦う自覚が必要です。

**現実的な使い方**: 銘柄の選定はファンダメンタルズ、売買のタイミングと損切り位置の設定にテクニカル、
という役割分担が個人には扱いやすい構成です。

## 8. ポートフォリオとアセットアロケーション

### 分散が「唯一のフリーランチ」と呼ばれる理由

値動きの相関が低い資産を組み合わせると、**期待リターンを大きく下げずにリスク（変動幅）だけを下げられます**。
これは統計的な性質であり、銘柄選択の腕とは無関係に得られる効果です。

分散の3つの軸:
1. **銘柄分散**: 個別株なら最低15〜20銘柄。それ未満だと1社の不祥事で資産が壊れる。
2. **業種分散**: 同じ業種を並べても分散にならない（銀行株5社は実質1銘柄）。
3. **地域・通貨分散**: 日本株だけだと、円と日本経済に給与と資産の両方を賭ける形になる。

### インデックス vs 個別株

| | インデックス投資 | 個別株投資 |
| --- | --- | --- |
| 期待リターン | 市場平均 | 市場平均を上回ることも下回ることもある |
| 必要な労力 | ほぼゼロ | 決算読解・継続的な追跡 |
| 分散 | 自動的に効く | 自分で作る必要がある |
| 向く人 | 大多数 | 分析が好きで、時間を割ける人 |

長期の統計では、**アクティブファンドの大半がインデックスに負けます**（コストの差が主因）。
個別株をやるなら、「コア（インデックス）+ サテライト（個別株）」として、
資産の一部に限定する構成が現実的です。

### アセットアロケーションの目安

リターンのばらつきの大半は**銘柄選択ではなく資産配分**で説明されます。
まず「株式：現金・債券」の比率を決め、それから中身を選びます。

- 保守的: 株式30〜40%
- 標準: 株式50〜70%
- 積極的: 株式80〜100%（長期・若年・収入が安定している場合）

### リバランス

配分が崩れたら元に戻す作業。年1回、または配分が±5%以上ずれたときに実施します。
機械的に「上がった資産を売り、下がった資産を買う」ことになるため、
**感情を排した逆張り**として機能します。

## 9. リスク管理

### ポジションサイジング（これが最重要）

「何を買うか」より「いくら買うか」の方が、資産曲線への影響は大きいです。

```
1回の取引で許容する損失額 = 総資産 × 1〜2%
購入株数 = 許容損失額 ÷ (購入価格 − 損切り価格)
```

例: 総資産300万円、1トレードのリスク許容 1%（3万円）、
株価2,000円で損切り1,800円（-200円）なら → 3万円 ÷ 200円 = **150株**。

この枠組みを使うと、「損切り幅が広い＝ポジションを小さくする」が自動的に守られます。

### 損切りルール

- **買う前に**損切り価格を決める（買った後に決めると必ず甘くなる）
- 損切りの根拠は「サポートを割った」「投資した前提が崩れた」など**シナリオの否定**であるべきで、
  「-10%」といった数字だけのルールはボラティリティの高い銘柄で機能しにくい
- **ナンピン（下落中の買い増し）は、当初の計画に含まれていた場合のみ**。
  含み損の穴埋めのためのナンピンは、失敗を大きくする行為です

### 最大ドローダウンの非対称性

損失からの回復に必要なリターンは、損失率に対して非線形に増えます。

| 下落率 | 元に戻すために必要な上昇率 |
| --- | --- |
| -10% | +11% |
| -20% | +25% |
| -33% | +50% |
| -50% | +100% |
| -80% | +400% |

**大きな損失を避けることが、大きな利益を狙うことより効きます。**

### レバレッジと信用取引

- 信用取引は損失が投資元本を超えることがあります（追証）。
- レバレッジ型ETF（2倍・3倍）は日次リバランスのため、**横ばい相場で価値が減衰**します（減価）。
  長期保有には向きません。
- 初心者が最初に飛ばすべきでない段階です。現物で数年経験してから検討してください。

## 10. 行動バイアス

投資の失敗の多くは知識不足ではなく、**判断の癖**が原因です。

| バイアス | 症状 | 対策 |
| --- | --- | --- |
| 損失回避 | 利益は早く確定し、損失は塩漬け（**処分効果**） | 買う前に損切り・利確ラインを書く |
| 確証バイアス | 自分の保有銘柄に好意的な情報だけ集める | 反対意見（空売り論拠）を必ず1つ探す |
| アンカリング | 「買値」に固執して判断する | 「今この株を持っていなかったら、今日買うか？」と自問する |
| 後知恵バイアス | 「あのとき分かっていた」と思い込む | 売買前に理由を記録し、後で答え合わせする |
| 群集心理・FOMO | 話題の銘柄に高値で飛び乗る | 買う理由が「上がっているから」なら見送る |
| 授かり効果 | 保有しているだけで価値を過大評価する | 定期的にポートフォリオをゼロベースで見直す |
| オーバートレード | 何かしていないと不安で売買を繰り返す | 「何もしない」を有効な選択肢として明示する |

### 投資日記のすすめ

売買のたびに次を記録します。これがバイアスに対する最も実効性のある対策です。

1. 買った理由（想定シナリオ）
2. 想定が崩れる条件（=損切り条件）
3. 目標株価とその根拠
4. 売却時: シナリオ通りだったか、判断は妥当だったか（結果ではなく**プロセス**を評価する）

## 11. コストと複利

### 複利の効果

年利5%で運用した場合の元本1に対する倍率:

| 期間 | 5% | 7% |
| --- | --- | --- |
| 10年 | 1.63倍 | 1.97倍 |
| 20年 | 2.65倍 | 3.87倍 |
| 30年 | 4.32倍 | 7.61倍 |

**時間が最大の武器**です。少額でも早く始めることの価値がここにあります。

### コストは確実なマイナスリターン

信託報酬 年1.5% と 年0.1% の差は、30年で最終資産の**30%以上**の差になります。
リターンは不確実ですが、コストは確実に効きます。

- 投資信託は**信託報酬**（保有中ずっとかかる）を最優先で確認する
- 「毎月分配型」「テーマ型」「ラップ口座」は高コストになりやすい
- 売買を繰り返すと、税金の先払いで複利が削られる（**課税の繰り延べ効果**を失う）

## 12. 情報源と学習ロードマップ

### 一次情報（最優先）

- **決算短信 / 有価証券報告書**: 企業のIRサイト、EDINET
- **決算説明会資料・書き起こし**: 経営者が何を語ったか
- **東証の適時開示情報（TDnet）**: 開示のリアルタイム確認
- **日銀・FRBの声明、金融政策決定会合**: 金利環境の把握

SNS・掲示板・YouTubeは、**仮説を得る場所であって判断の根拠にはしない**こと。
ポジショントーク（自分が持っている銘柄を宣伝する）が構造的に混ざります。

### 90日ロードマップ

**Day 1–30: 土台づくり**
- 生活防衛資金の確保、証券口座（特定口座 源泉徴収あり + NISA）の開設
- インデックス投信で少額積立を開始し、口座操作と値動きに慣れる
- 課題図書を1冊読む（例: 『敗者のゲーム』チャールズ・エリス）

**Day 31–60: 分析の基礎**
- 自分が知っている業界の企業3社の決算短信を読む
- P/L・B/S・C/Fの主要項目をスプレッドシートに転記して比較
- 主要指標（PER・PBR・ROE・営業CF）を同業で並べる

**Day 61–90: 実践と検証**
- 少額（総資産の5%以内）で1〜2銘柄を購入。買う前に投資日記を書く
- ポジションサイジングと損切りラインを事前に決めて運用
- 月末に振り返り: 判断プロセスは妥当だったか（結果の良し悪しとは分けて評価する）

## 13. やってはいけないことリスト

- ❌ 生活費・近い将来使うお金で投資する
- ❌ 借金・信用取引で始める
- ❌ 1銘柄に資産を集中させる
- ❌ 損切りラインを決めずに買う
- ❌ 含み損の穴埋め目的でナンピンする
- ❌ SNSの推奨銘柄をそのまま買う
- ❌ 「絶対に儲かる」「元本保証で高利回り」に近づく（詐欺の定型句）
- ❌ 相場の下落局面で、計画外の全売却をする
- ❌ 値動きを1日中見る（判断の質が下がり、取引回数だけ増える）
- ❌ 理解できない商品を買う（仕組債、複雑な仕組みのETNなど）

## 14. 用語集

| 用語 | 意味 |
| --- | --- |
| 約定 | 売買が成立すること |
| 単元株 | 売買の最小単位。日本株は原則100株 |
| 板 | 売り・買いの注文が価格ごとに並んだ表 |
| ザラ場 | 取引時間中（寄付と引けの間） |
| 寄付 / 引け | 取引開始時 / 終了時の売買 |
| ストップ高・安 | 1日の値幅制限の上限・下限 |
| 権利確定日 | 配当・株主優待を受け取る権利が確定する日 |
| 配当落ち | 権利確定の翌営業日に配当分だけ株価が下がる現象 |
| 増資 | 新株発行。1株あたりの価値が薄まる（希薄化） |
| 自社株買い | 発行済株式を減らす。EPSが増える株主還元策 |
| 時価総額 | 株価 × 発行済株式数。会社の市場評価額 |
| ボラティリティ | 価格変動の大きさ。リスクの代表的な指標 |
| ドローダウン | 最高値からの下落率 |
| 押し目 | 上昇トレンド中の一時的な下落 |
| 決算またぎ | 決算発表を保有したまま迎えること（変動が大きい） |
| 織り込み済み | 情報がすでに株価に反映されている状態 |
| インデックス | 市場全体の値動きを示す指数（TOPIX、S&P500など） |
| ETF | 取引所に上場していて株のように売買できる投資信託 |
| 信託報酬 | 投資信託の保有中にかかる年率コスト |
| ドルコスト平均法 | 定額を定期的に買い付ける手法。購入単価が平準化される |
